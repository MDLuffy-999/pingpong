# 🏓 Neon Ping Pong

**Neon Ping Pong** --- небольшая аркадная игра в стиле классического
Pong, написанная на Python с использованием Pygame. В игре два игрока
соревнуются на одном компьютере: отбивайте мяч ракетками и постарайтесь
первыми набрать 5 очков.

## 🎮 Возможности

-   Главное меню с кнопками «Играть», «Управление» и «Выход»
-   Режим для двух игроков на одном компьютере
-   Режимы сложности (лёгкий, средний, сложный)
-   Отображение счёта
-   Ускорение мяча во время матча
-   Экран паузы
-   Подсказки по управлению в интерфейсе
-   Неоновое оформление
-   Уменьшение ракетки

## 🕹️ Управление

  Игрок          Движение вверх   Движение вниз
  -------------- ---------------- ---------------
  Левый игрок    `W`              `S`
  Правый игрок   `↑`              `↓`

-   `ESC` --- пауза / продолжить
-   Побеждает игрок, первым набравший **5 очков**

## ⚙️ Требования

-   Python 3
-   Pygame

## 🚀 Установка и запуск

### Windows

1.  Установите Python 3:
    [python.org/downloads](https://www.python.org/downloads/)

2.  Откройте терминал в папке проекта.

3.  Установите зависимости:

    ``` bash
    python -m pip install -r requirements.txt
    ```

4.  Запустите игру:

    ``` bash
    python main.py
    ```

### macOS

1.  Установите Python 3, если он ещё не установлен:
    [python.org/downloads](https://www.python.org/downloads/)

2.  Откройте Terminal и перейдите в папку проекта.

3.  Создайте виртуальное окружение:

    ``` bash
    python3 -m venv .venv
    ```

4.  Активируйте его:

    ``` bash
    source .venv/bin/activate
    ```

5.  Установите зависимости:

    ``` bash
    python -m pip install -r requirements.txt
    ```

6.  Запустите игру:

    ``` bash
    python main.py
    ```

### Linux

1.  Установите Python 3, pip и модуль для виртуальных окружений.

    Ubuntu / Debian / Linux Mint:

    ``` bash
    sudo apt update
    sudo apt install python3 python3-pip python3-venv
    ```

    Fedora:

    ``` bash
    sudo dnf install python3 python3-pip
    ```

    Arch / Manjaro:

    ``` bash
    sudo pacman -S python python-pip
    ```

2.  Откройте терминал и перейдите в папку проекта.

3.  Создайте виртуальное окружение:

    ``` bash
    python3 -m venv .venv
    ```

4.  Активируйте его:

    ``` bash
    source .venv/bin/activate
    ```

5.  Установите зависимости:

    ``` bash
    python -m pip install -r requirements.txt
    ```

6.  Запустите игру:

    ``` bash
    python main.py
    ```

Быстрый запуск одной командой (скрипт сам создаст окружение, поставит
зависимости и запустит игру):

``` bash
bash run_linux.sh
```

Если окно игры не открывается, проверьте, что вы запускаете её в
графической сессии (X11 или Wayland), а не в терминале без экрана.
