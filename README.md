# 🏓 Neon Ping Pong

**Neon Ping Pong** --- небольшая аркадная игра в стиле классического
Pong, написанная на Python с использованием Pygame. В игре два игрока
соревнуются на одном компьютере: отбивайте мяч ракетками и постарайтесь
первыми набрать 5 очков.

## 🎮 Возможности

-   Главное меню с кнопками «Играть», «Управление» и «Выход»
-   Режим для двух игроков на одном компьютере
-   Отображение счёта
-   Ускорение мяча во время матча
-   Экран паузы
-   Подсказки по управлению в интерфейсе
-   Неоновое оформление
-   Уменьшение ракетки

## 🕹️ Управление

  Игрок          Движение вверх   Движение вниз
  -------------- ---------------- ---------------
  Левый игрок    `W`              `S`
  Правый игрок   `↑`              `↓`

-   `ESC` --- пауза / продолжить
-   Побеждает игрок, первым набравший **5 очков**

## ⚙️ Требования

-   Python 3
-   Pygame

## 🚀 Установка и запуск

### macOS

1.  Установите Python 3, если он ещё не установлен:
    [python.org/downloads](https://www.python.org/downloads/)

2.  Откройте Terminal и перейдите в папку проекта.

3.  Создайте виртуальное окружение:

    ``` bash
    python3 -m venv .venv
    ```

4.  Активируйте его:

    ``` bash
    source .venv/bin/activate
    ```

5.  Установите зависимости:

    ``` bash
    python -m pip install -r requirements.txt
    ```

6.  Запустите игру:

    ``` bash
    python main.py
    ```

### Windows

1.  Установите Python 3:
    [python.org/downloads](https://www.python.org/downloads/)

2.  Откройте терминал в папке проекта.

3.  Установите зависимости:

    ``` bash
    python -m pip install -r requirements.txt
    ```

4.  Запустите игру:

    ``` bash
    python main.py
    ```
